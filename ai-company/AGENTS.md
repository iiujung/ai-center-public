# ai-company 共用總則

`~/AI-Center/ai-company` 是老闆（待填：稱呼）的 git repo，裡面放幾個彼此獨立的公司，加一層大家共用的工具層：

| 資料夾 | 是什麼 | 總規矩 |
|---|---|---|
| `公司1/` | 正職工作（待填：公司／部門） | `公司1/AGENTS.md` |
| `個人1/` | 工作以外的生活與自媒體（待填） | `個人1/AGENTS.md` |
| `共用/` | 各公司共用的 Skill 和工具 | `共用/AGENTS.md` |

開工時從自己公司的資料夾開 session（例如 `~/AI-Center/ai-company/個人1`），這份共用總則會一起讀到；接著照該公司的總規矩上崗。

## 公司彼此分開
- 各公司只讀寫自己的資料夾和 `共用/`，不讀另一家公司的檔案，除非老闆明說。
- 正職工作的資料只放 `公司1/`，生活和自媒體的資料只放 `個人1/`。

## 路徑（多台電腦通用）
- repo 根目錄：`~/AI-Center/ai-company`；新電腦把 repo clone 到這裡。
- 寫進檔案和交接時一律用完整路徑，用 `~/AI-Center/ai-company/...` 開頭。
- repo 外面、只在本機的資料夾（都在 `~/AI-Center/`，不進 git，每台電腦各自保管）：
  - `~/AI-Center/個人1-private/`、`~/AI-Center/個人1-big-files/`
  - `~/AI-Center/公司1-big-files/`

## 金鑰
- API 金鑰只放一份：`~/AI-Center/ai-company/.env`（已被 `.gitignore` 排除），各公司共用。格式見 `.env.example`。
- 誰都不把金鑰貼進對話、寫進其他檔案或印出來。

## 回報
- 回報、交接時，指向完成的檔案一律寫成可以點開的 markdown 連結，不要只寫純文字路徑。

## git
- 只有一個 repo，各公司都提交到這裡。只提交自己改的檔（`git add` 指定檔名，不要 `git add -A`）。
- commit 訊息開頭標公司，例如「個人1：…」「公司1：…」「共用：…」。
- 推上 GitHub 前先 `git pull`，另一家公司可能剛推過。

## 加一家、刪一家
- 加：複製一份現有公司資料夾當起點，清空 `工作看板/任務/`、各員工的 `工作記錄/` 和填過的內容，改名後把裡面所有寫死的舊名字一起換掉；上面的表格、repo 外的資料夾清單跟著加一行。
- 刪：刪掉那家的資料夾和 repo 外對應的資料夾，上面的表格跟著刪。
- 從零開始建，用 `kb-setup` Skill；已經有舊知識庫要搬進來，用 `kb-migrate` Skill（都在 `~/AI-Center/ai-company/共用/工具/技能/`）。完整說明見 `~/AI-Center/使用說明.md`。
