# 工具/

## 放什麼
放用到的工具和帳號說明（不寫密碼和金鑰）。用好一個工具的過程、設定方法和踩過的坑放 `最佳實踐/`。

## 不放什麼
不放查來的原始資料（去 `../研究/`）；不放 Skill 的實體（在共用層，見下）。

## 怎麼分
一個工具或一個主題一個檔案。`最佳實踐/` 底下也是一個主題一個檔案。

## Skill 放哪
1. 實體只有一份，在各公司共用的 `~/AI-Center/ai-company/共用/工具/技能/<名字>/SKILL.md`（寫法見 `~/AI-Center/ai-company/共用/AGENTS.md`）。
2. 要給本公司用，在公司根目錄掛兩個軟連結，都指向那份實體（在 `~/AI-Center/ai-company/公司1` 執行）：
   - `ln -s ../../../共用/工具/技能/<名字> .claude/skills/<名字>`（Claude Code 讀）
   - `ln -s ../../../共用/工具/技能/<名字> .agents/skills/<名字>`（Codex、Gemini、OpenCode 等讀）
3. 改 Skill 只改共用層的實體，掛連結的兩處不用動。

## 怎麼命名
檔名用工具或主題名稱，不加日期。
